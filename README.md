# Music — MC killler (mrsiktyyy.github.io)

Положите всё в корень репозитория:
```
index.html  tracks.json  .nojekyll
css/style.css   js/app.js
songs/    ← mp3 (Атлантида.mp3, РепЛовушки.mp3, Семья.mp3, ВойнаВРепе.mp3)
covers/   ← обложки .jpg (Атлантида.jpg …) и обложки плейлистов pl-<id>.jpg
icons/    ← иконки кнопок .svg (play.svg, pause.svg …)
```
Новая песня: mp3 → songs/, обложка → covers/, строка в tracks.json.
Если файла обложки/иконки нет — показывается цветной градиент/символ.
История и «Нравится» хранятся в cookies браузера.
